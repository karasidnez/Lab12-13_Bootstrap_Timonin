## Описание проекта
Данный проект создан в рамках лабораторной работы по изучению CSS-фреймворка Bootstrap 5.
Что было изучено:

- Компоненты: Navbar, Cards, Forms, Modal, Accordion
- Утилитные классы
- Адаптивные изображения
- Валидация форм
- Кастомизация стилей
